# operationd8979.github.io

Developer website of **Hoàng Dũng IT**, served by GitHub Pages at
https://operationd8979.github.io — the Website named in every Google Play listing.

- `index.html` — the developer page, one section per app.
- `<app>/privacy/{vi,en,ja}/` — each app's privacy policy (Task Manager: `task-manager/`).
- `app-ads.txt` — added at the root once the AdMob account exists; one file covers every app.
- `.nojekyll` — serve the files as they are, without Jekyll.

The pages are generated from the app repositories' `docs/release/site/`; edit them there
first, then copy here.
